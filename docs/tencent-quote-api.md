# 腾讯行情接口调研文档

> 面向 LongbridgeA 选股/分析场景的数据源调研  
> 最后更新：2026-11-15  
> 状态：社区逆向 + 多源交叉验证，**非官方文档**

---

## 1. 概述与定位

腾讯财经公开 HTTP 接口是目前国内最常用、最稳定的免费 A 股实时行情来源之一：

- **无需注册 / API Key**
- 响应快（通常几十到一两百毫秒）
- 支持批量查询
- 覆盖沪深 A 股、指数、ETF，部分接口也支持港股 / 美股

本项目**仅做选股与分析**，不涉及交易，因此重点使用：

| 能力 | 推荐接口 | 优先级 |
|------|----------|--------|
| 实时快照（含五档） | `qt.gtimg.cn/q=` | P0 |
| 简要快照（列表用） | `qt.gtimg.cn/q=s_` | P0 |
| 当日分时 | `web.ifzq.gtimg.cn/.../minute/query` | P0 |
| 日/周/月 K 线 | `web.ifzq.gtimg.cn/.../fqkline/get` | P0 |
| 分钟 K 线 | `ifzq.gtimg.cn/.../kline/mkline` | P0 |
| 股票搜索 | `smartbox.gtimg.cn` | P0 |
| 资金流向 | `qt.gtimg.cn/q=ff_` | P2 |

**重要提醒**：接口为非官方公开端点，字段靠社区逆向，存在变更与限流风险。实现时必须做抽象层，方便后续切换数据源。

## 2. 代码规范（Symbol 规则）

| 市场 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 上海主板 / 科创板 | `sh` | `sh600519`（茅台）、`sh688111` | 6 / 688 开头 |
| 深圳主板 / 创业板 | `sz` | `sz000001`（平安银行）、`sz300750` | 000 / 001 / 002 / 300 开头 |
| 北交所 | `bj` | `bj830799` | 8 开头（部分接口支持有限） |
| 指数 | `sh` / `sz` | `sh000001`（上证）、`sz399001`（深成）、`sh000300`（沪深300） |
| ETF | 同对应市场 | `sh510300`、`sz159915` | |
| 港股（扩展） | `hk` / `r_hk` | `hk00700` | 报价常用 `r_hk` |
| 美股（扩展） | `us` | `usAAPL` | |

**批量查询**：多个代码用英文逗号连接  
`https://qt.gtimg.cn/q=sh600519,sz000001,sh000001`

**编码**：响应多为 **GBK**，客户端必须按 GBK 解码，否则中文名称乱码。

## 3. 实时行情快照（核心）

### 3.1 完整快照

```
GET https://qt.gtimg.cn/q={code[,code...]}
```

或 `http://qt.gtimg.cn/q=...`（两者均可）

**返回格式**（非 JSON）：

```
v_sh600519="51~贵州茅台~600519~1460.00~...~";
```

- 以 `~` 分隔字段
- 多只股票时多行 / 分号分隔
- 变量名形如 `v_sh600519`

### 3.2 A 股完整字段索引（社区共识，2026 年仍有效）

| 索引 | 字段 | 说明 | 单位 / 备注 |
|------|------|------|-------------|
| 0 | 未知 / 市场标记 | 常为 `1` 或 `51` | 可忽略 |
| 1 | 名称 | 中文简称 | |
| 2 | 代码 | 6 位裸代码 | |
| 3 | 最新价 | 当前成交价 | 元 |
| 4 | 昨收 | 前收盘价 | 元 |
| 5 | 今开 | 今日开盘价 | 元 |
| 6 | 成交量 | | **手**（1 手 = 100 股） |
| 7 | 外盘 | 主动买入量 | 手 |
| 8 | 内盘 | 主动卖出量 | 手 |
| 9–18 | 买一～买五 | 价 + 量交替 | 价(元) / 量(手) |
| 19–28 | 卖一～卖五 | 价 + 量交替 | 价(元) / 量(手) |
| 29 | 最近逐笔 | 时间/价/量/方向... | 盘中才有 |
| 30 | 更新时间 | | `YYYYMMDDHHMMSS` |
| 31 | 涨跌额 | 现价 - 昨收 | 元 |
| 32 | 涨跌幅 | | **百分比数值**，如 `1.23` 表示 1.23% |
| 33 | 最高 | 当日最高 | 元 |
| 34 | 最低 | 当日最低 | 元 |
| 35 | 复合字段 | 现价/量/额 | 较少直接使用 |
| 36 | 成交量 | 与 6 可能重复 | 手 |
| 37 | 成交额 | | **万元** |
| 38 | 换手率 | | % |
| 39 | 市盈率 (TTM) | | |
| 43 | 振幅 | | %（注意：不是 PB） |
| 44 | 流通市值 | | **亿元** |
| 45 | 总市值 | | **亿元** |
| 46 | 市净率 (PB) | | |
| 47 | 涨停价 | | 元 |
| 48 | 跌停价 | | 元 |
| 49 | 量比 | | 可能为空字符串，需判空 |

**常见踩坑**：

1. 索引 43 是振幅，不是 PB；PB 在 46。
2. 成交额单位是**万元**，市值单位是**亿元**。
3. 成交量单位是**手**（主板/创业板），科创板部分场景是股，实现时需注意。
4. 量比、部分财务字段可能为空，必须 `parse` 前判空。
5. 编码必须用 GBK。

### 3.3 简要快照（列表 / 自选推荐）

```
GET https://qt.gtimg.cn/q=s_{code}
```

示例：`q=s_sh600519`

字段更少，适合 Watchlist 高频轮询：

| 索引 | 含义 |
|------|------|
| 1 | 名称 |
| 2 | 代码 |
| 3 | 最新价 |
| 4 | 涨跌额 |
| 5 | 涨跌幅 |
| 6 | 成交量（手） |
| 7 | 成交额（万） |
| 9 | 总市值（约） |

### 3.4 资金流向（扩展）

```
GET https://qt.gtimg.cn/q=ff_{code}
```

适合选股器「资金面」条件，优先级 P2。

## 4. 分时数据

```
GET https://web.ifzq.gtimg.cn/appstock/app/minute/query?code={code}
```

示例：`code=sh600519`

**返回**：标准 JSON；单条常见为 `时分 价格 累计成交量 [累计成交额]`。

## 5. K 线数据

### 5.1 日 / 周 / 月 K（前复权推荐）

```
GET https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},{period},{start},{end},{count}[,{adjust}]
```

| 参数 | 说明 |
|------|------|
| code | `sh600519` |
| period | `day` / `week` / `month` |
| start / end | `YYYY-MM-DD`，可空 |
| count | 条数，单次通常 ≤ 640 |
| adjust | `qfq`（前复权） / `hfq` / 空（不复权） |

行布局：`[date, open, close, high, low, volume]`。

### 5.2 分钟 K 线（mkline）

**推荐 Host**（实测 `web.ifzq` 可能 301）：

```
GET https://ifzq.gtimg.cn/appstock/app/kline/mkline?param={code},{interval},,{count}
```

- `interval`：`m1` / `m5` / `m15` / `m30` / `m60`
- 主要支持 A 股；一般为**不复权**
- 数量常见 ≤ 320

响应片段示例：

```json
{
  "code": 0,
  "data": {
    "sh600519": {
      "m5": [
        ["202611131325", "1428.17", "1424.89", "1429.00", "1423.46", "520.00", {}, "0.42"]
      ]
    }
  }
}
```

行布局：`[YYYYMMDDHHMM, open, close, high, low, volume, …]`（OHLC 顺序与日 K 一致）。

本仓库：`MinuteInterval` + `TencentQuoteClient::fetch_mkline`，默认 `mkline_base = https://ifzq.gtimg.cn`。

### 5.3 数据注意点

- 科创板成交量单位可能是「股」，其余多为「手」
- 北交所支持不完整
- 翻页：日线可用 start/end 分段拉取后拼接

## 6. 股票搜索（smartbox）

```
GET https://smartbox.gtimg.cn/s3/?v=2&t=all&c=1&q={keyword}
```

- 响应 GBK；`v_hint="market~code~name~pinyin~kind^..."`
- 映射为 `SearchHit`，可用 `is_a_share()` 过滤 A 股

---

## 7. 请求建议与最佳实践

- Header：`User-Agent` + `Referer: https://gu.qq.com/`
- 快照批量建议 ≤ 50～100；自选轮询 3～5 秒
- K 线限流：Host 轮换 + 缓存
- 字段空串先判空再 parse
