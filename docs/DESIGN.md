# LongbridgeA 设计文档

> 选股与分析工具的 UI / UX 与设计系统说明  
> 对标 Longbridge Pro 的行情与分析体验，**不含交易相关界面**  
> 最后更新：2026-11-15

---

## 1. 设计原则

1. **信息密度优先**：专业终端，默认深色，数据优先于装饰。
2. **可扫读**：涨跌、量能、状态用颜色与对齐快速识别。
3. **可组合**：页面由可复用 Panel 组成，后期支持自定义 Workspace。
4. **键盘友好**：导航、切换周期、搜索均可快捷键完成。
5. **范围克制**：不出现下单、持仓、委托等交易控件。

### 2.4 字体

- **界面**：系统无衬线（macOS SF Pro / Windows Segoe UI / Linux 默认）
- **数字 / 行情**：等宽或表格数字特性（`tnum`），避免跳动
- **字号建议**
  - 标题：16–18px
  - 正文：13–14px
  - 辅助：12px
  - 行情大数字：20–28px（个股价）
  - 表格：12–13px

### 2.5 与 gpui-kit 的映射

实现时优先使用 gpui-kit / gpui-base 语义色：

- `background` / `foreground`
- `surface` / `surface_foreground`
- `primary` / `accent`
- `muted` / `border`
- 涨跌色作为**应用层扩展 token**，不硬编码在组件库默认主题中

## 3. 整体布局架构

参考 Longbridge Pro 的「系统布局 + 标签页」思路，初期做**固定系统布局**，预留自定义 Workspace。

```
┌─────────────────────────────────────────────────────────────┐
│  Title Bar / 全局搜索 / 主题切换 / 设置                      │
├──────────┬──────────────────────────────────────────────────┤
│          │  Tab Bar（自选 | 个股详情 | 选股器 | 行情 | …）    │
│  Sidebar │──────────────────────────────────────────────────│
│  导航     │                                                  │
│          │              Main Content (Panel 区域)           │
│  · 自选  │                                                  │
│  · 行情  │                                                  │
│  · 选股  │                                                  │
│  · 分析  │                                                  │
│  · 资讯  │                                                  │
│  · 设置  │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

### 3.1 区域职责

| 区域 | 职责 |
|------|------|
| Sidebar | 一级导航，可折叠；激活项用 brand 色 + soft 背景 |
| Tab Bar | 同一功能下的多实例（如多个个股详情）或子视图 |
| Main | 由多个 Panel 组成；可左右 / 上下分割 |
| 全局搜索 | 顶部或 `Ctrl/Cmd + K`，对接腾讯搜索接口 |

### 3.2 初期系统页面（不可删）

1. **自选**（Watchlist）
2. **个股分析**（Stock Detail）
3. **选股器**（Screener）
4. **市场概览**（Market）
5. **设置**（Settings）

后期再加「自定义布局」与多窗口。

## 4. 核心页面线框说明

### 4.1 自选（Watchlist）

**目标**：快速扫盘、分组管理、一键进入个股分析。

```
┌────────────────────────────────────────────────────────────┐
│ 自选  [全部 ▼]  [+ 分组]  [刷新]              🔍 搜索自选   │
├────────────┬───────────────────────────────────────────────┤
│ 分组列表    │ 表格：代码 | 名称 | 最新 | 涨跌幅 | 涨跌额     │
│ · 默认     │       | 成交额 | 换手 | 量比 | 最高 | 最低    │
│ · 核心持仓  │ 行：涨红 / 跌绿；点击整行 → 打开个股分析 Tab  │
│ · 观察池   │ 右键：置顶 / 移出 / 加到分组 / 复制代码        │
│            │ 表头可排序；支持列显示设置                    │
└────────────┴───────────────────────────────────────────────┘
```

**交互要点**

- 数据源：腾讯简要或完整快照，3–5s 轮询（可配置）
- 双击或 Enter：打开个股分析
- 支持多选 + 批量加入分组
- 空状态：引导搜索添加标的

**组件**

- 分组树 / 列表
- 虚拟滚动表格（gpui-kit Table / 自研）
- 涨跌色文本组件 `PriceChange`

---

### 4.2 个股分析（Stock Detail）

**目标**：单标的全景分析（报价 + 分时/K 线 + 基础信息），无交易区。

```
┌────────────────────────────────────────────────────────────┐
│ 贵州茅台  600519.SH    1,460.00  +12.00  +0.83%   [+自选]  │
│ 高 1,472  低 1,448  开 1,455  昨收 1,448  换手 0.42% …     │
├────────────────────────────────────────────────────────────┤
│ [分时] [日K] [周K] [月K] [5分] [15分] [30分] [60分]  指标▼ │
├──────────────────────────────────┬─────────────────────────┤
│                                  │ 五档 / 明细（只读）      │
│         图表区域                  │ 买一 … 买五              │
│      （分时 or K线）              │ 卖一 … 卖五              │
│                                  │─────────────────────────│
│                                  │ 关键信息                 │
│                                  │ 市值 / PE / PB / 振幅    │
│                                  │─────────────────────────│
│                                  │ 简要资讯入口（可选）      │
└──────────────────────────────────┴─────────────────────────┘
```

**交互要点**

- 顶部报价条固定，数字等宽，涨跌即时变色
- 图表支持：
  - 周期切换
  - 常用指标：MA、VOL、MACD、RSI、BOLL（可配置显示）
  - 画线工具（趋势线、水平线等）— 可二期
- 五档仅展示，无「买入/卖出」按钮
- 同一标的多周期可后续支持分屏（自定义布局阶段）

**组件**

- `QuoteHeader`
- `ChartWorkbench`（分时 + K 线共用容器）
- `OrderBook`（五档只读）
- `KeyStats`（市值、PE、PB、换手等）

### 4.3 选股器（Screener）— 核心重点

**目标**：条件组合筛选 A 股，结果可加入自选。

```
┌────────────────────────────────────────────────────────────┐
│ 选股器   [预设策略 ▼]  [保存条件]  [清空]                    │
├─────────────────────┬──────────────────────────────────────┤
│ 条件面板             │ 结果列表（虚拟表）                     │
│                     │ 代码 名称 现价 涨跌幅 成交额 市值 …    │
│ ▸ 行情条件           │ 勾选 → [加入自选] [打开分析]          │
│   涨跌幅  [min][max] │                                      │
│   成交额  [min][max] │ 状态：共 N 只 · 扫描中 / 完成         │
│   换手率  …          │                                      │
│   量比    …          │                                      │
│                     │                                      │
│ ▸ 技术条件（二期）    │                                      │
│   MA 多头 / 金叉 …   │                                      │
│                     │                                      │
│ ▸ 估值条件           │                                      │
│   市值 / PE / PB …   │                                      │
│                     │                                      │
│ [执行选股]           │                                      │
└─────────────────────┴──────────────────────────────────────┘
```

**条件分层（与数据源匹配）**

| 层级 | 条件示例 | 数据来源 |
|------|----------|----------|
| P0 行情 | 涨跌幅、成交额、换手、量比、振幅、现价区间 | 腾讯快照 |
| P1 估值 | 总市值、流通市值、PE、PB | 腾讯快照字段 |
| P2 技术 | 站上 MA5/MA10、MACD 金叉等 | 本地用 K 线计算 |
| P3 资金 | 主力净流入等 | `ff_` 资金流（可选） |

**交互要点**

- 预设模板：如「放量上涨」「低价超跌」「高换手活跃」
- 条件可保存为命名策略
- 结果表支持排序、导出（二期）、批量加自选
- 扫描进度与取消

### 4.4 市场概览（Market）

**目标**：大盘与板块一眼可读。

```
┌────────────────────────────────────────────────────────────┐
│ 上证 3,xxx  +x.xx%   深成 …   创业板 …   沪深300 …          │
├──────────────────────┬─────────────────────────────────────┤
│ 涨跌分布               │ 热门板块 / 概念                      │
│ █ 上涨 n  █ 下跌 n    │ 名称 涨跌幅 领涨股                   │
│ 涨停 / 跌停 数量       │                                     │
├──────────────────────┴─────────────────────────────────────┤
│ 涨幅榜 | 跌幅榜 | 成交额榜 | 换手榜                           │
│ （表格，点击进个股分析）                                      │
└────────────────────────────────────────────────────────────┘
```

指数条可用腾讯批量快照；板块榜若腾讯不足，可二期接东财等扩展源。

## 5. 关键组件规范

### 5.1 `PriceChange`

- 输入：现价、昨收或涨跌额/幅
- 展示：`+1.23%` / `-0.56%`，颜色绑定 `up` / `down` / `flat`
- 等宽数字，避免布局抖动

### 5.2 行情表格行

- 行高约 28–32px
- Hover：`bg.elevated` 或轻微高亮
- 选中：左侧 brand 竖线或 soft 背景
- 涨跌列使用 `PriceChange`

### 5.3 图表容器

- 工具条：周期、指标、画线、截图（可选）
- 主图 + 副图（VOL / MACD）可拖拽调整高度
- 十字光标显示 OHLCV 与时间
- 无交易按钮、无订单线（范围排除）

### 5.4 空状态与加载

- 加载：骨架屏或中心 Spinner，避免整页白屏
- 空自选：插画/简文 +「搜索添加」
- 选股无结果：提示放宽条件

### 5.5 搜索

- 全局 `Ctrl/Cmd + K`
- 输入防抖 200–300ms
- 结果：代码、名称、市场标签
- 回车打开个股分析并可选「同时加入自选」

## 6. 导航与快捷键（初稿）

| 快捷键 | 作用 |
|--------|------|
| `Ctrl/Cmd + K` | 全局搜索 |
| `Ctrl/Cmd + 1..4` | 切换自选 / 行情 / 选股 / 设置 |
| `Ctrl/Cmd + W` | 关闭当前 Tab |
| `←` `→` | 个股内切换周期（可选） |
| `R` | 刷新当前视图数据 |
| `/` | 聚焦当前页搜索框 |

交易类快捷键一律不实现。

## 7. 响应与多屏

- **最小宽度**：约 1200px（专业桌面优先）
- 侧栏可折叠为图标模式
- 后期：多窗口（自选与个股分离）、多屏拖拽
- WASM 版：简化侧栏，优先单栏 + Tab
